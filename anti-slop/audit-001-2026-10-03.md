# UI/Mobile Audit — 2026-10-03

Mode: AFTER. This audit records findings only; application code has not been modified.

## Findings

1. **[HIGH] Tidak ada kontrol light/dark mode yang berfungsi**

   - Bukti: `src/components/reminder-dashboard.tsx` tidak memiliki state, persistence, atau tombol theme; `src/app/globals.css` hanya mendefinisikan palette terang di `:root`.
   - Dampak: pengguna tidak dapat memilih tema yang nyaman pada malam hari, dan permintaan button interaktif belum terpenuhi.
   - Aturan: R-21, C-2, C-4.
   - Rekomendasi: tambahkan toggle Sun/Moon yang menyimpan pilihan di `localStorage`, menghormati `prefers-color-scheme` saat belum ada pilihan, serta token warna dark yang tetap memenuhi kontras.

2. **[HIGH] Tombol aksi reminder di mobile terlalu kecil untuk disentuh**

   - Bukti: pada breakpoint mobile, `.row-actions button` berukuran `23px × 26px`; ukuran dasar `.table-actions button` hanya `27px × 27px`.
   - Dampak: edit, tunda, jeda, dan hapus mudah salah tekan pada layar sentuh. Screenshot juga menunjukkan beberapa ikon rapat di sisi kanan baris.
   - Aturan: R-03, R-35.
   - Rekomendasi: berikan area sentuh minimum sekitar `44px × 44px`, beri jarak antartombol, dan gunakan menu aksi atau bottom sheet jika empat aksi tidak muat.

3. **[HIGH] Dua kontrol header tidak memiliki perilaku**

   - Bukti: tombol `Pengaturan workspace` dan `Notifikasi` dirender sebagai `<button>` tanpa handler atau tujuan.
   - Dampak: pengguna mobile/desktop dapat menekan kontrol yang terlihat interaktif tetapi tidak mendapat respons.
   - Aturan: R-24, R-26, C-2.
   - Rekomendasi: hubungkan Pengaturan workspace ke Settings; untuk Notifikasi, tampilkan panel/status yang nyata atau hilangkan tombol sampai fiturnya tersedia.

4. **[MEDIUM] Header mobile terlalu padat dan memakai label yang sangat kecil**

   - Bukti: tiga tombol aksi berada dalam `.heading-actions`, sementara breakpoint mobile menurunkan ukuran font hingga `9px` dan menampilkan label panjang seperti “Bersihkan data lama”.
   - Dampak: hierarki New reminder melemah dan teks sulit dibaca pada lebar ponsel kecil.
   - Aturan: R-03, R-05, R-06.
   - Rekomendasi: jadikan New reminder sebagai CTA utama selebar penuh; pindahkan maintenance actions ke menu “More” atau section terpisah dengan label yang tetap terbaca.

5. **[MEDIUM] Status mobile berpotensi bertumpuk dengan metadata reminder**

   - Bukti: `.status-pill` diposisikan `absolute` di dalam `.table-row`, sedangkan detail tanggal berada di area reminder yang sama.
   - Dampak: pada judul/pesan panjang atau font lebih besar, status dapat menimpa tanggal atau ruang kosong menjadi tidak konsisten.
   - Aturan: R-03, R-35, C-4.
   - Rekomendasi: jadikan status bagian dari layout normal pada mobile, misalnya satu baris metadata di bawah judul, bukan posisi absolut.

6. **[LOW] Belum ada arah desain tertulis untuk menjaga konsistensi tema**

   - Bukti: project tidak memiliki `DESIGN.md`; palette, typography, dan dial mobile belum didokumentasikan sebagai keputusan produk.
   - Dampak: perubahan light/dark dan mobile mudah menjadi kumpulan override tanpa hierarki yang konsisten.
   - Aturan: R-01, R-05, R-06, R-37.
   - Rekomendasi: tetapkan token warna, ukuran teks, radius, target sentuh, dan perilaku navigasi mobile sebelum implementasi final.

## Prioritas yang disarankan

Mulai dari temuan **1, 2, dan 3**, lalu perbaiki **4 dan 5** dalam pass mobile yang sama. Temuan 6 menjadi acuan agar implementasi tema tidak menghasilkan override yang terpisah-pisah.

## Resolution

All findings were approved and addressed in the following changes:

- Added a persistent light/dark theme toggle with system preference fallback.
- Added dark theme tokens and component states for the dashboard surfaces, controls, dialogs, and status pills.
- Increased mobile touch targets and spacing for navigation, theme, reminder actions, and header actions.
- Added a visible mobile Menu label and constrained the breadcrumb so the header does not overflow.
- Connected workspace settings and notification controls to real settings navigation.
- Reflowed mobile reminder status into the normal grid instead of absolute positioning.
- Added project design direction in `DESIGN.md`.
- Added `.next/dev` to TypeScript exclusions so stale development route validators do not block production builds.

Verification: contrast checks passed for the primary light, dark, and CTA pairs; `npm run lint` passed; `npm run build` passed.
